# SchoolPro — School Management System

**Task ID:** `WD-SCH-001` · **Company:** Data Alcott Systems (`freeinternships.in`)

A responsive, frontend-only School Management System built with **HTML5, CSS3, and JavaScript** using in-memory / `localStorage` persistence.

## Features
- **Role-Based Authentication**: Sign In & Register for **Admin**, **Teacher**, and **Parent** roles (with Demo Quick Login).
  - **Admin**: Full access to add, edit, delete, and manage students, teachers, classes, attendance, grades, fees, timetables, exam schedules, and announcements.
  - **Teacher & Parent**: Read-only access to view records, schedules, report cards, fee receipts, and reports.
- **Dashboard**: School statistics, enrollment bar chart, upcoming exam schedule, and recent announcements.
- **Student Management**: Add, edit, delete, search, filter by Class (1–10) & Section (A–C), photo upload, and Student Profile modal.
- **Teacher Management**: Manage faculty profiles, subjects, and assigned classes.
- **Class & Section Management**: Configure Classes 1–10, Sections A–C, rooms, and class teachers.
- **Attendance**: Daily Present/Absent tracking and student attendance percentage summary.
- **Grade Management**: Marks entry, automatic percentage & letter grade calculation, and printable Report Cards.
- **Fee Management**: Fee structure across 5 categories (Tuition, Transport, Library, Sports, Examination), payment collection, and printable Fee Receipts.
- **Timetable & Exam Schedule**: Weekly class timetable grid and upcoming exam schedule.
- **Parent Communication**: Notice board announcements and parent contact directory.
- **Reports & Dark Mode**: Export Student, Attendance, Fee, and Grade reports to **CSV** or **PDF/Print**, plus a **Dark Mode** toggle.

## Running Locally
Open `index.html` in a browser or serve the `school-pro` folder with any static HTTP server.
